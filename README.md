# **Credit Card Fraud Detection System**

## Project Overview
The Credit Card Fraud Detection System is designed to detect fraudulent credit card transactions using machine learning techniques. The system uses historical transaction data to train models that can classify transactions as either legitimate or fraudulent. The project includes data preprocessing, model training, evaluation, and deployment in a user-friendly web application using Streamlit.

## Technologies Used
Python (Scikit-learn, Pandas, NumPy)

VScode (for prototyping and experiments)

Matplotlib / Seaborn (for data visualization)

## For Dataset
https://www.kaggle.com/mlg-ulb/creditcardfraud
